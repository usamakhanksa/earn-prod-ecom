**Setup steps:**
1. **Account Creation** — Sign up on MTurk Requester account; verify identity and tax info; link AWS account.
2. **Task Design** — Define task requirements clearly; set fair payment ($0.05-2.00/task); create quality control questions; upload batch files.
3. **API Integration example** (Python, boto3):

```python
import boto3

client = boto3.client('mturk',
   region_name='us-east-1',
   endpoint_url='https://mturk-requester.us-east-1.amazonaws.com'
)

response = client.create_hit(
   Title='Image Categorization Task',
   Description='Categorize images into predefined categories',
   Reward='0.10',
   AssignmentDurationInSeconds=600,
   LifetimeInSeconds=86400,
   Question='<ExternalQuestion xmlns="http://mechanicalturk.amazonaws.com/AWSMechanicalTurkDataSchemas/2006-07-14/ExternalQuestion.xsd"><ExternalURL>https://your-task-url.com</ExternalURL><FrameHeight>600</FrameHeight></ExternalQuestion>'
)
```
