# ROLE

You are a senior full-stack architect, UI/UX designer, product engineer, security engineer, and DevOps engineer.

Build a complete, production-ready, responsive web application for a **global country-aware marketplace and monetization platform**.

The platform combines:

1. Country-aware e-commerce/product discovery
2. Product categories and product listings
3. Supplier registration and supplier portal
4. Customer registration/login
5. Affiliate registration and affiliate dashboard
6. Product affiliate links/referrals
7. Dropshipping supplier integration
8. Task/micro-task/offer discovery
9. Ad/offer engagement section
10. Referral and rewards system
11. Earnings and payout dashboard
12. Admin management
13. Country-specific marketplaces and payment methods
14. Analytics and conversion tracking
15. Contact/support system

Do NOT only provide a plan or sample code.

Build the application architecture and implementation in one complete response, using a clean production structure. Clearly separate frontend, backend, database, API integrations, authentication, dashboards, and configuration.

---

# 1. PRODUCT VISION

Create a platform where a visitor opens the website and the system automatically determines their likely country.

The platform then dynamically changes:

* Country
* Currency
* Language
* Product availability
* Product categories
* Recommended products
* Supplier availability
* Marketplace sources
* Payment methods
* Shipping information
* Affiliate offers
* Task/offer availability
* Promotional content

Example:

A visitor from Saudi Arabia should see Saudi-relevant products, categories, suppliers, currencies, payment options, and marketplace sources.

A visitor from the United States should see US-relevant products, suppliers, marketplaces, payment methods, and offers.

Do not hard-code the entire frontend around one country.

Create a reusable country configuration system.

# 6. AUTOMATIC COUNTRY DETECTION

Implement country detection.

Use a layered strategy:

1. Existing user profile country
2. User-selected country
3. Browser locale
4. IP/geolocation API
5. fallback country

Never rely exclusively on IP.

Create a service:

```text
CountryDetectionService
```

Return:

```json
{
  "countryCode": "SA",
  "countryName": "Saudi Arabia",
  "currency": "SAR",
  "language": "ar",
  "timezone": "Asia/Riyadh"
}
```

Persist country preference in cookie/session/user profile.

Allow the user to change it manually.

Show:

"Delivering to Saudi Arabia"

with a change-country option.

**How you earn as a publisher/developer:**  
You integrate the platform’s ad unit or SDK. When a user completes an action, the advertiser pays the platform, and the platform shares a portion of that revenue with you. It’s usually a **revenue share (50‑85%)** or a fixed CPM/CPA.

**Why it earns daily money:**

## 2. Easy Integration: Website vs. Mobile App

### A) For Websites (Web Publishers)

Integration is typically a **single JavaScript tag** that creates an offerwall or reward widget.

**Step‑by‑step (generic):**
1. Sign up on the platform’s publisher panel.
2. Get your unique JavaScript embed code.
3. Place the code where you want the reward button/offerwall to appear (usually a “Earn Coins” page or popup).
4. Configure a **postback URL** so your website knows when a user completes an action (to credit virtual currency, points, etc.).
5. The widget loads and displays a list of tasks (videos, surveys, app installs) tailored to the user’s country/device.

**Example code snippet (conceptual):**
```html
<div id="offerwall-widget"></div>
<script src="https://platform.example.com/publishers/XXXXX.js"></script>
<script>
  OfferWall.init({
    publisherId: 'YOUR_ID',

    onReward: function(amount, transactionId) {
       // Credit user in your system
       creditUserPoints(amount);
    }
  });
</script>
```
Most platforms provide a complete code generator – just copy & paste.

### B) For Mobile Apps (iOS / Android)

You’ll integrate an **SDK** (often via CocoaPods, Gradle, or Swift Package Manager).

**Standard flow:**
1. Add the SDK dependency to your project.
2. Initialize it in your `AppDelegate`/`Application` class with your API key.
3. Place a “Show Rewarded Video” or “Open Offerwall” button in your app.
4. Implement the callback/listener to detect when a reward should be granted.
5. The SDK handles ad loading, caching, and showing – it’s fully UI‑ready.

Both methods are designed for fast integration (minutes to a couple of hours). The platforms below clearly mark which integration they support.
